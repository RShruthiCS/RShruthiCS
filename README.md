## 🚀 Featured Projects

### 🤖 [AI Student Assistant](https://github.com/RShruthiCS/AI-Student-Assistant)
-Built an end-to-end RAG pipeline that extracts text from any uploaded PDF, chunks and embeds it using sentence-transformers/all-MiniLM-L6-v2, and stores vectors in ChromaDB for semantic retrieval.
-Integrated GPT-3.5 via OpenAI API to answer questions, explain concepts, and generate quizzes from document content — all from a single natural language input.
-Deployed as a Streamlit web app with PDF file upload, session state management, and real-time responses — shipped as a fully functional user-facing product.
- **Tools:** Python, OpenAI API, LLMs, RAG, ChromaDB, Streamlit
