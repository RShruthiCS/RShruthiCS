## 🚀 Featured Projects

### 🤖 [AI Student Assistant](https://github.com/RShruthiCS/AI-Student-Assistant)
-Built an end-to-end RAG pipeline that extracts text from any uploaded PDF, chunks and embeds it using sentence-transformers/all-MiniLM-L6-v2, and stores vectors in ChromaDB for semantic retrieval.
-Integrated GPT-3.5 via OpenAI API to answer questions, explain concepts, and generate quizzes from document content — all from a single natural language input.
-Deployed as a Streamlit web app with PDF file upload, session state management, and real-time responses — shipped as a fully functional user-facing product.
- **Tools:** Python, OpenAI API, LLMs, RAG, ChromaDB, Streamlit

### 🏦 [Banking System](https://github.com/RShruthiCS/cs157a-BankingSystem)
-Designed a normalized PostgreSQL schema with constraints and role-based access for [customers, tellers, and admins].
-Implemented CRUD operations and transactions to keep records consistent.
-Built a Java/JDBC backend tested with Docker.
- **Tools:** Java, SQL

### 📉 [Telco Customer Churn Analysis](https://github.com/RShruthiCS/telco-customer-churn-analysis)
Analyzed a telecom customer dataset in **PostgreSQL** and built an interactive **Tableau** dashboard to find what drives customers to cancel.
- **Key finding:** _e.g. month-to-month customers churned at X% vs Y% on annual contracts_
- **Tools:** PostgreSQL, SQL, Tableau
